# Ordo 示例产品知识

> 用途：在真实业务数据交付前，用于验证导入、解析、切块、索引、问答、引用、版本和备份闭环。本文档不包含客户数据。

## 产品定位

Ordo 是一个本地优先的知识管理与严格证据问答产品。它把原始文档转换为可审计的 Markdown、JSON 和知识块，并通过不可变 KnowledgeRelease 为问答固定知识版本。

## 启动方式

在项目根目录运行 `npm start`。服务默认监听 `http://127.0.0.1:8790/`，同时提供 Web 工作台和 `/api/v1` 接口。首次启动会创建受管数据目录和本地所有者会话。

## 创建知识库

在“知识库 > 数据配置”中创建知识库。系统会同时创建默认数据集和不可变 IndexProfile。知识库负责处理与索引配置，数据集负责组织面向具体业务用途的材料。

## 导入与解析

支持上传 MD、TXT、CSV、XLSX、DOCX、PPTX、带文字层 PDF，以及一层 ZIP、TAR、TAR.GZ 或 TGZ 压缩包。图片和扫描 PDF 会安全登记并进入人工复核，只有配置并验证 OCR 或 VLM Provider 后才生成视觉文本。

## 构建知识版本

解析完成后，在“构建知识索引”中检查知识块并发布版本。系统会快照当前块修订，验证来源链，在隔离状态构建全文与本地向量投影，通过后原子切换活动 Release。构建失败不会破坏旧活动版本。

## 严格证据问答

新会话选择一个知识库并固定活动 Release。问答依次执行问题解析、问题向量化、检索路由、多路召回、重排、构建提示词和回答生成七个阶段。结果融合位于多路召回内部。证据不足时系统拒答，回答引用只能指向实际参与生成且仍有权限访问的知识块。

## 数据安全

模型密钥和数据库密码只保存在 AES-256-GCM 秘密库中，普通数据库记录和 API 响应只保存引用与掩码。上传拒绝脚本、HTML 和可执行文件；压缩包阻止路径穿越、链接、嵌套展开和资源超限。所有管理写请求需要本机会话和 CSRF 令牌。

## 备份与恢复

备份包含 SQLite 一致性快照、受管 Blob 和标准知识产物，并记录逐文件 SHA-256。恢复始终写入新的隔离目录，完成数据库完整性和对象校验后才允许人工切换数据根目录；当前运行实例不会被覆盖。
