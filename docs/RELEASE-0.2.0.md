# Inktable 0.2.0 发布说明

**日期**：2026-08-13
**定位**：v7「知识库优先」架构的首个发布候选。0.1.0 是能用的文件索引器，
0.2.0 是能查、能问、能回溯证据的个人知识库。

## 界面

- 全新「纸墨」设计系统：墨青主色、朱砂印章品牌标、暖纸底色，
  深浅色模式完整适配，单一样式来源（`workbench.css`）。
- 统一三栏工作台：文件管理 / 文件详情与证据 / 知识问答同屏常驻，
  无顶层模式切换。
- 彩色文件类型徽标、卡片化详情与引用、聚焦环、自定义滚动条。
- 修复顶栏品牌区被 macOS 窗口按钮遮挡的问题。
- 新增 `tools/preview/`：Electron + 模拟数据的界面截图工具，
  五个状态（工作台/搜索/设置/深色/紧凑）可一键回归。

## 检索质量（72 题冻结评测，同日 RRF 对照）

| 指标 | RRF 对照 | 0.2.0 |
|---|---|---|
| Recall@5（文档命中） | 85.0% | **95.0%** |
| 严格通过率（含答案关键词） | 73.3% | **90.0%** |
| MRR@10 | 73.2% | 80.5% |
| nDCG@10 | 77.3% | 84.0% |
| 跨块/跨文档综合题 | 70% | 85% |
| 检索 p50 | 35.9ms | 46.0ms |

改进项（全部经逐题运行时探针取证后实施）：

1. **比较类问题子查询分解**——「A 和 B 分别…」按实体展开为附加召回路线。
2. **查询词抽取修复**——中文空格片段强制重分词，杜绝「版本开发」类粘连词。
3. **近重复治理**——`text_hash` 跨内容去重 + 向量余弦 0.95 近重复软降权，
   文件的多个编辑副本不再刷榜。
4. **本地重排 v3**——IDF 加权覆盖、词邻近度、数值答案、显式类型、
   文件名覆盖特征；同文档冗余覆盖软降权。

## 证据压缩（M4 达标，关键词代理口径）

- 关键词证据保留率 95.0%（门槛 95%）
- 字符压缩率中位数 61.1%（门槛 ≥35%）
- offset 往返错误 0；压缩阶段 P95 3.7ms
- 新增可重复评测：`uv run python tests/run_compress_eval.py`

## 大库性能与可靠性

- 向量检索矩阵进程内缓存（写路径失效）：3 万分片合成库实测
  检索 p50 247.9ms → 44.0ms，p95 717.3ms → 77.6ms；真实库 p50 24ms。
- 修复库超过约 3.2 万分片后语义检索静默消失的缺陷
  （全量 active id 作为 SQL 绑定参数超出 SQLite 32766 上限，
  异常被降级路径吞掉）。改为先检索、后小集合核对活跃版本。

## 问答与可审计性

- 引用由 EvidenceSpan 驱动：`span_id` + 分片/全文双层 offset，逐字节可回溯。
- 四条后置校验全部留痕（`validation` 字段），降级路径显式可见。
- 新增 `GET /runs/{trace_id}`：回读最近 50 条检索 trace（内存态、含鉴权、
  无正文无查询原文）。

## 已知限制（如实）

- Rerank 模型门槛未过：nDCG/MRR 相对 RRF +8.7%/+10.0%，低于 15% 选型线。
  F29/F31/P19 类片级排序与 X06 类近重复深召回需要真 Cross-Encoder 与
  模糊重复分组，属下一版本。
- 「引用支持率/正确拒答率」两项 LLM 指标待配置真实模型后跑批。
- 检索侧拒答仍不可行（本次重新标定：误拒 ≤5% 下正确拒答率仅 58.3%），
  维持「不硬拒 + 置信度标注」。
- 无代码签名（需 Apple 开发者账号），首次打开需右键 → 打开。
- 扫描件 PDF 无 OCR；源码类文件只登记元数据。
