# 静墨（Quiet Ink）

「静墨」以克制取代炫技。形体由极少的几何关系构成：一个承载知识的容器、一滴凝聚的信息，以及足够宽裕的留白。符号必须在 Dock、菜单栏和 16 像素界面中都保持清楚，任何不能增强识别度的装饰都应被删除。

色彩像墨落在冷色纸面上。近黑底色提供安静而稳定的空间，青绿色承担主要识别，暖金只作为一点温度和方向。材质保持近乎平面，仅用极轻的明度变化区分层次；不使用霓虹、镜面、写实纹理或多余高光。

尺度强调一个强轮廓，而不是许多小细节。图形中心稳定，四周留有均匀呼吸空间；圆角、曲率和笔画端点经过反复校准，使整体既有数字产品的精度，也保留墨迹自然落下的柔和感。

构图追求静态平衡中的轻微张力：墨滴不是孤立的水滴，而与下方承托线共同形成「墨」与「桌」的关系。语义藏在形体里，不依靠文字解释；熟悉产品的人能读到知识沉淀，第一次看到的人也只会感到一个完整、现代的符号。

最终执行必须像经过无数次缩放检查与光学校正。轮廓、间距、颜色和暗色模式表现都要体现大师级的耐心；桌面图标、页面标志与字标必须来自同一套几何母版，避免任何风格漂移。
