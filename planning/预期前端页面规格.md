## 09 问答流程 > 检索路由

- 左主区（白卡）：
  - 左上「输入问题」卡：问题原文。
  - 左下「路由配置」卡：数据范围 / 权限过滤 ⓘ / 应用画像 / 兜底策略 ⓘ，值为绿色链接文字。
  - 中央「检索路由器」圆形节点，左侧输入卡以折线箭头接入，右侧四条绿色/灰色折线分别指向：向量检索（已启用胶囊，预估召回 N，置信度 x）/ 全文检索 / 知识图谱 / 结构化查询（未启用，灰胶囊，灰线）。每张通道卡有淡绿圆底图标。
  - 下方「通道参数」表：通道 / 状态(圆点) / TopK / 超时时间 / 权重 / 预估耗�� / 预估成本。
- 右栏「路由依据」：意图匹配（置信度）/ 可用索引（健康；向量检索 vX、全文检索 vX、知识图谱 vX 各带绿点）/ 权限约束（可访问范围、命中率）/ 路由原因（要点列表，每条右侧分数）；底部「综合置信度」大号绿字。
