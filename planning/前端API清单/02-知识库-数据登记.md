### 1.1 核心业务口径与交互规则（用户已锁定）

1. **顶部 6 大数据接入方式**：
   - **`[ ↑ 上传文件 ]`**：点击触发原生文件选择对话框（支持多选），支持 PDF、Word (.docx/.doc)、Excel (.xlsx/.xls)、PPT (.pptx)、Markdown、TXT 等主流文档；
   - **`[ 📁 导入目录 ]`**：选择文件夹批量递归导入；
   - **`[ 🗜 导入压缩包 ]`**：上传 `.zip` / `.tar.gz` 压缩包，系统自动在隔离沙箱解压并登记内部有效文件；
   - **`[ ☁ 连接网盘 ]`**：弹窗配置 WebDAV、百度网盘、阿里云盘、坚果云等远程存储；
   - **`[ 🛢 连接数据库 ]`**：弹窗配置并连接市面上主流的基本所有数据库（MySQL、PostgreSQL、Oracle、SQL Server、Doris、ClickHouse、MongoDB 等），支持指定表/视图抽取并配置定时同步；
   - **`[ 💻 本机探测 ]`**：界面保留按钮，**先占位**，后续阶段再深入实现。
2. **📌【02 页面多语种检测前置提醒在此生效】**：
   - 上传或导入文件时，系统进行语种探测；若发现非目标语言（如外语），立即弹出确认窗口询问：  
     `[ 转换到目标语言入库 ]` / `[ 保持原样入库 ]` / `[ 取消 ]`。
3. **顶部筛选药丸与 5 大类分类体系**：
   - 筛选药丸分为：`[ 全部 ]` + **5 大具体类型**（`[ 文件 ]`、`[ 目录 ]`、`[ 网盘 ]`、`[ 数据库 ]`、`[ 本机 ]`）；
   - 点击不同药丸时，**左栏来源树与中间表格精准联动过滤**；
   - **右栏（最近导入 + 需要处理）作为全域安全监控看板，始终全局常驻展示，绝不因筛选而隐藏漏报**！
4. **中间表格 6 大列显示规范**：
   - **名称**：带格式图标（Word、PDF、Excel、PPT、Markdown、文件夹）；
   - **来源**：如实标注数据源头（如“手动上传”、“WebDAV”、“PostgreSQL业务库”等）；
   - **同步状态（文件搬运）**：**必须带动态百分比进度条**（如 `⟳ 同步中 68%` 带绿色进度条，完成后变 `🟢 已同步`，失败变 `🔴 同步失败`）；
   - **处理状态（内容加工切块）**：保持状态机（`⚪ 待处理` ➔ `⟳ 解析中 3/12` ➔ `🟢 已完成` / `🔴 失败`）；
   - **所属数据集**：已分配则显示数据集名称；**若尚未分配，严格显示为灰色徽标 `未配置`**；
     - **★ 核心数据源联动**：数据登记页面中所有涉及【所属数据集】的下拉选择器（包括单文件上传、目录导入、数据库抽取弹窗中的目标数据集下拉，以及表格中将「未配置」重新指派数据集的操作下拉），**其下拉选项 100% 动态来源于「数据集」页面左侧已创建的数据集列表 (`GET /api/v1/datasets`)**！用户在数据集页面新建了多少个数据集，此下拉框就实时呈现多少个选项（外加默认的「未配置」项），实现双页面强数据联动！
   - **最近更新**：记录该记录的最后一次操作时间戳（年月日时分）。

## 二、页面所需全部接口契约

### 2.1 获取已登记数据清单 (GET /api/v1/sources)

- **接口定位**：供中间表格使用，支持按 5 大分类药丸、状态、分页查询。
- **请求方法**：`GET`
- **请求路径**：`/api/v1/sources`
- **查询参数**：
  | 参数名 | 类型 | 必填 | 默认值 | 说明 |
  |---|:---:|:---:|:---:|---|
  | `type` | `string` | 否 | `all` | 药丸筛选：`all` / `file` / `directory` / `cloud` / `database` / `local` |
  | `page` | `integer` | 否 | `1` | 当前页码 |
  | `limit` | `integer` | 否 | `10` | 每页条数 |
- **响应载荷 (200 OK)**：
  ```json
  {
    "data": [
      {
        "id": "src_doc_01",
        "name": "产品需求说明书.docx",
        "fileType": "docx",
        "sourceCategory": "file",
        "sourceName": "企业资料",
        "syncStatus": "synced",          // synced(已同步) / syncing(同步中) / failed(失败)
        "syncProgress": 100,             // 同步进度百分比 (0-100)
        "processStatus": "completed",    // pending(待处理) / parsing(解析中) / completed(已完成) / failed(失败)
        "processProgressText": null,     // 如 "3/12"
        "datasetId": "ds_prod",          // 若未分配则为 null
        "datasetName": "产品数据集",     // 若未分配则为 null，前端统一展示为 "未配置"
        "updatedAt": "2025-05-20 10:23"
      },
      {
        "id": "src_dir_02",
        "name": "产品手册目录",
        "fileType": "folder",
        "sourceCategory": "directory",
        "sourceName": "企业资料",
        "syncStatus": "syncing",
        "syncProgress": 68,              // 动态进度条渲染数据
        "processStatus": "parsing",
        "processProgressText": "3/12",
        "datasetId": "ds_prod",
        "datasetName": "产品数据集",
        "updatedAt": "2025-05-20 10:18"
      },
      {
        "id": "src_doc_03",
        "name": "技术图纸目录",
        "fileType": "folder",
        "sourceCategory": "local",
        "sourceName": "本机已确认",
        "syncStatus": "pending",
        "syncProgress": 0,
        "processStatus": "pending",
        "processProgressText": null,
        "datasetId": null,               // 👈 未分配！前端展示 "未配置"
        "datasetName": null,
        "updatedAt": "2025-05-20 09:31"
      }
    ],
    "meta": { "total": 254, "page": 1, "limit": 10 }
  }
  ```

### 2.3 单/多文件上传 (POST /api/v1/files)

- **接口定位**：点击【上传文件】选择本地文件上传。
- **请求方式**：`POST` (`multipart/form-data`)
- **字段**：`files[]` (文件二进制), `datasetId` (可选，不选则为未配置)
- **响应 (200 OK)**：返回新登记的文件列表，附带多语种检测警告（如有）：
  ```json
  {
    "data": {
      "uploadedCount": 2,
      "items": [
        { "id": "file_01", "name": "产品手册.pdf", "detectedLanguage": "zh-CN", "mismatch": false },
        { "id": "file_02", "name": "Overview.pdf", "detectedLanguage": "en-US", "mismatch": true } // 👈 触发弹窗询问
      ]
    }
  }
  ```

### 2.4 连接主流数据库抽取数据 (POST /api/v1/connectors)

- **接口定位**：点击【连接数据库】保存配置并触发数据抽取。
- **请求方法**：`POST`
- **请求体 (Request Body)**：
  ```json
  {
    "dbType": "mysql", // 支持 mysql, postgresql, oracle, sqlserver, doris, clickhouse, mongodb 等
    "host": "192.168.1.50",
    "port": 3306,
    "database": "crm_db",
    "username": "readonly_user",
    "password": "Password123!",
    "tables": ["customer_profiles", "order_contracts"],
    "targetDatasetId": "ds_client",
    "syncSchedule": "0 2 * * *" // 每天凌晨2点定时同步
  }
  ```

---

### 2.5 分配或更改所属数据集 (PATCH /api/v1/sources/:id/dataset)

- **接口定位**：在表格中对显示为 **`未配置`** 的资料，一键分配归属到指定数据集。
- **请求方法**：`PATCH`
- **请求路径**：`/api/v1/sources/:id/dataset`
- **请求体**：`{ "datasetId": "ds_tech_01" }`
- **响应 (200 OK)**：状态更新成功，表格内该行由 `未配置` 变为 `技术资料集`。

---

### 2.6 右侧常驻监控与告警接口 (GET /api/v1/sources/recent & attention)

- `GET /api/v1/sources/recent-activities`: 获取最近 5~10 条导入动态；
- `GET /api/v1/sources/attention-items`: 获取右下角【需要处理】告警清单（如同步失败的文件、待配置项）。

---

### 2.7 动态获取所属数据集下拉选项 (GET /api/v1/datasets)

- **接口定位**：**跨页面强联动**——供数据登记页面的所有【所属数据集】下拉选择框使用，实时拉取用户在「数据集」页面左侧已创建好的数据集列表。
- **请求方法**：`GET`
- **请求路径**：`/api/v1/datasets`
- **响应载荷 (200 OK)**：
  ```json
  {
    "data": [
      { "id": null, "name": "未配置 (暂不分配)", "isDefault": true },
      { "id": "ds_prod", "name": "产品使用文档", "documentCount": 1284 },
      { "id": "ds_tech", "name": "技术资料", "documentCount": 982 },
      { "id": "ds_market", "name": "市场资料", "documentCount": 517 }
    ]
  }
  ```
- **业务表现**：用户在数据集页面通过 `+` 新建了几个数据集，这里下拉框就秒级刷新出对应的新数据集供勾选分配！

### 2.8 数据库连通性实时测试 (POST /api/v1/connectors/test)

- **接口定位**：在【连接数据库】弹窗中点击【⚡ 测试连接】按钮时触发，实时探测目标数据库网络与账号权限。
- **请求方法**：`POST`
- **请求体**：`{ "dbType": "postgresql", "host": "127.0.0.1", "port": 5432, "database": "ordo_biz", "username": "postgres", "password": "..." }`
- **响应 (200 OK)**：`{ "success": true, "latencyMs": 14, "tablesCount": 28, "viewsCount": 4 }`

---

### 2.9 删除已登记数据源 (DELETE /api/v1/sources/:id)

- **接口定位**：在中间表格中删除已登记的文件或数据连接。
- **请求方法**：`DELETE`
- **请求路径**：`/api/v1/sources/:id`
- **响应 (200 OK)**：`{ "success": true, "deletedId": "src_001" }`
