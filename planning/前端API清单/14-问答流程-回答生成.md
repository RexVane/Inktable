## 二、本页面全部 API 契约总览表 (共 7 个 API)

| 序号 | 请求方式 | 接口路径 | 对应前端组件 / 触发时机 | 核心功能说明 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/traces/:traceId/stages/generation` | 页面初次加载 / 切换至此步骤 | **主数据源**：获取最终问答全貌（GPT-5请求元数据、Token 消耗统计、最终格式化回答 Markdown、3 条佐证切片、引用合规指标、各阶段耗时） |
| **2** | `GET` | `/api/v1/traces/:traceId/pipeline` | 顶部与底部 8 阶段耗时链条 | 获取整条流水线 8 个步骤的精准执行耗时 |
| **3** | `POST` | `/api/v1/traces/:traceId/stages/generation/regenerate` | 回答下方 `[ ⟳ 重新生成 ]` 按钮 | **流式重新推断**：支持 SSE (Server-Sent Events) 流式重新向模型请求回答，并就地更新 Token 与回答内容 |
| **4** | `POST` | `/api/v1/traces/:traceId/feedback` | 回答下方 `[ 👍 有帮助 ]` / `[ 👎 没帮助 ]` | **效果反馈闭环**：提交问答质量评分与人工判定标签，沉淀至模型对齐标注集 |
| **5** | `POST` | `/api/v1/traces/:traceId/save-qa` | 回答下方 `[ 💾 保存 ]` 按钮 | **资产沉淀**：将本条优质问答对直接归档沉淀至知识库的 FAQ 问答库或精选知识库 |
| **6** | `GET` | `/api/v1/traces/:traceId/waterfall` | 底部右侧 `[ 📑 查看完整 Trace ]` 按钮 | **链路全景甘特图**：拉取 OpenTelemetry 格式的全链路微服务调用 Span 树与耗时瀑布 |
| **7** | `POST` | `/api/v1/traces/:traceId/replay-all` | 底部右侧 `[ ⟳ 从问题解析重跑 ]` 按钮 | **全局冷启动重跑**：使用该 Query 从 Stage 1 重新触发整个 RAG 问答链路并生成新 Trace |

### 2. 重新生成回答 (SSE 流式或同步) (`POST /api/v1/traces/:traceId/stages/generation/regenerate`)
* **触发场景**：点击回答下方 `[ ⟳ 重新生成 ]` 按钮。
* **请求方法**：`POST`
* **请求路径**：`/api/v1/traces/:traceId/stages/generation/regenerate`
* **请求头**：`Accept: text/event-stream` 或 `application/json`
* **请求体 (JSON)**：
```json
{
  "temperature": 0.20,
  "overrideModel": "GPT-5"
}
```
* **SSE 事件流响应**：
```
event: delta
data: {"content": "您可以按照以下步骤..."}

event: done
data: {"totalTokens": 2240, "durationMs": 680}
```

## 四、前端交互与动态状态机行为

1. **角标与引用卡片高亮联动**：
   - 鼠标悬停在回答正文中的 `[1]`、`[2]`、`[3]` 角标时，右侧对应的引用证据卡片产生浅绿色呼吸发光高亮；反之，点击右侧引用卡片，正文中所有对应引用编号随之聚焦闪烁。
2. **点赞与点踩互斥状态**：
   - 点击「有帮助」后图标变为实心绿色并禁用二次点击；点击「没帮助」则弹出简要改进建议原因收集框。
3. **返回智能问答导航**：
   - 点击底部右侧 `[ ➔ 返回智能问答 ]` 按钮，界面平滑过渡至 Page 15 (`15-AI应用-智能问答`)，并将当前问题与生成的答复自动载入主聊天对话流中。
