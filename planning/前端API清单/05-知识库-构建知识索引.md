# 05-知识库-构建知识索引 前端 API 清单与交互契约

> **文档定位**：对应原型设计稿 `05-知识库-构建知识索引.png`。  
> **流水线位置**：**第四站·向量检索与知识切片中枢**（`数据登记 ➔ 数据集 ➔ 数据解析 ➔ 构建知识索引 ➔ 知识库管理/智能问答`）。  
> **核心使命**：负责把 Station 3（数据解析）清洗提取出的结构化文本，进行分块切片管理（Chunks）、文本向量化（Embeddings 1536维）、向量数据库索引构建（HNSW Graph）、全文倒排索引（BM25），提供分块微调（编辑、拆分、合并、禁用）、一致性血缘追踪（Chunk ➔ Vector ➔ Collection ➔ Index）、检索召回验证与不可变版本冻结发布（Release v7 ➔ v8）。

## 二、页面全生命周期接口总览表 (共 21 个 API)

| 序号 | 请求方式 | 接口路径 | 对应前端组件 / 触发时机 | 核心功能说明 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/datasets/:id/indexing/pipeline` | 顶部四阶段进度指示条 | 获取切块、向量化、向量索引、全文索引四大阶段执行状态与完成百分比 |
| **2** | `GET` | `/api/v1/datasets/:id/indexing/stats` | 顶部四大核心指标卡片 | 获取知识块总量 (8652)、已向量化 (8610)、待更新 (42)、活跃索引版本 (v7) |
| **3** | `GET` | `/api/v1/datasets/:id/documents` | 筛选栏【文档】下拉框 | 拉取数据集下关联的全部原始文档列表供过滤 |
| **4** | `GET` | `/api/v1/datasets/:id/chapters` | 筛选栏【章节】下拉框 | 获取解析后文档树提取出的大纲章节列表 |
| **5** | `GET` | `/api/v1/datasets/:id/chunks` | 中栏【知识块列表】与筛选回显 | 分页检索知识块列表，支持关键词、ID、文档、章节、Token 范围与状态过滤 |
| **6** | `GET` | `/api/v1/chunks/:id` | 右栏上方【知识块编辑】 | 点击列表单项，拉取指定知识块完整 Markdown 内容、Token 数、修订历史与来源页码 |
| **7** | `POST` | `/api/v1/chunks/:id/revisions` | 知识块编辑 `[保存并增量更新]` | 保存对分块内容的修订编辑，生成不可变分块修订版本 |
| **8** | `POST` | `/api/v1/chunks/:id/vectorize` | 下拉菜单 `[保存并立即向量化]` / 单块 `[立即计算]` | 单块级立即重算向量特征（调用 text-embedding 模型生成 1536 维高维向量） |
| **9** | `POST` | `/api/v1/chunks/:id/split` | 知识块操作 `[ ✂ 拆分 ]` 按钮 | 将一个过长或跨语义分块按指定断句点拆分为 2 个独立知识块 |
| **10** | `POST` | `/api/v1/chunks/merge` | 知识块操作 `[ ⮑ 合并 ]` 按钮 | 将当前分块与相邻的前后分块融合成一个知识块 |
| **11** | `POST` | `/api/v1/chunks/:id/toggle-disable` | 知识块操作 `[ 🚫 禁用 ]` 按钮 | 切换知识块的禁用/启用状态，被禁用的知识块从向量检索库逻辑屏蔽 |
| **12** | `GET` | `/api/v1/chunks/:id/lineage` | 右栏下方【索引构建一致性视图】 | 获取当前块端到端血缘 DAG：数据块 ➔ 向量记录 ➔ 集合 (Collection) ➔ HNSW 索引健康度 |
| **13** | `GET` | `/api/v1/documents/:id/pages/:pageNum` | 知识块编辑来源超链 `[来源:导论p12 ↗]` | 点击来源跳转，唤起弹窗预览该分块在原始 PDF 对应页的高保真快照 |
| **14** | `POST` | `/api/v1/releases/:id/search` | 底部 `[ 查询验证 ]` 弹窗 | 输入测试 Query 语句，模拟向量检索测试，返回 Top-K 命中知识块与相似度得分 |
| **15** | `POST` | `/api/v1/datasets/:id/releases` | 底部 `[ 发布版本 ]` 按钮 | 冻结当前已向量化的全部知识块为全新只读发行版（如 `v8`），激活并供问答检索调用 |
| **16** | `GET` | `/api/v1/datasets/:id/releases` | 版本历史与发布确认弹窗 | 获取历史发布版本轨迹（v1 ~ v7），比对发布变更差异（新增/修改/删除分块数） |
| **17** | `POST` | `/api/v1/datasets/:id/indexing/vectorize-pending` | 阶段 2 `[ ⚡ 立即向量化 42 个待更新块 ]` | 批量并发计算全部待更新分块的高维特征向量，动态推进进度条至 100% |
| **18** | `POST` | `/api/v1/datasets/:id/indexing/rebuild-hnsw` | 阶段 3 `[ 🔄 重建 HNSW 图索引 ]` | 触发全量重建 4 层 Skip-List 概率跳表图索引，并唤起构建进度条 |
| **19** | `POST` | `/api/v1/datasets/:id/indexing/optimize-index` | 阶段 3 `[ 🧹 索引碎片压缩整理 ]` | 执行向量索引空间整理与碎片压缩优化，释放物理内存/磁盘空间 |
| **20** | `POST` | `/api/v1/datasets/:id/indexing/rebuild-bm25` | 阶段 4 `[ ⚡ 重建倒排索引库 ]` | 重建结巴分词词典与 BM25 全文检索倒排索引 |
| **21** | `PUT` | `/api/v1/datasets/:id/indexing/hybrid-weights` | 阶段 4 `[ 保存权重 ]` / 混合检索滑动条 | 实时持久化保存 Dense 语义与 Sparse 词频双路混合检索融合加权配比 |

## 五、端到端全业务流程闭环（4 大交互场景）

### 场景 1：分块纠错与即时重新向量化
1. 用户在中栏搜索框输入 `人工智能概述`，按回车；
2. 列表刷新，用户点击 `chunk_0000001`；
3. 右栏编辑器回显正文，用户发现有个错别字，在 textarea 中修改完毕；
4. 点击 `[ 保存并增量更新 ∨ ]` ➔ 下拉选择 `保存并立即向量化`；
5. 前端调用 `POST /api/v1/chunks/chunk_0000001/revisions` ➔ 成功后调用 `POST .../vectorize`；
6. 右侧一致性视图“向量记录”从黄色警报变为绿色 `已同步 (1536维)`，顶部“待更新”数字由 42 降为 41！

### 场景 2：过长文本一键拆分
1. 用户发现 `chunk_0000003` 长度为 623 Tokens，超出检索最佳粒度；
2. 点击右栏 `[ ✂ 拆分 ]` 按钮；
3. 弹出智能拆分窗口，自动推荐在段落换行符处切开；
4. 用户确认拆分 ➔ 调用 `POST /api/v1/chunks/chunk_0000003/split`；
5. 服务端返回两个新生成的块 `chunk_0000003_a` 与 `chunk_0000003_b`；
6. 顶部总知识块数变为 `8,653`，列表自动增行并高亮第一块。

### 场景 3：发布前在线检索仿真验证
1. 用户完成一批分块的修订调整；
2. 点击底部 `[ 查询验证 ]` 按钮；
3. 弹出“向量检索验证台”，输入真实问答：*“什么是工业大模型？”*；
4. 点击“开始测试” ➔ 调用 `POST /api/v1/releases/rel_v7/search`；
5. 列表呈现 3 条召回结果，第一条匹配度 `0.9241`，并高亮命中的正文字句；
6. 验证无误，关闭弹窗。

### 场景 4：发布全新知识版本（v7 ➔ v8）
1. 用户点击右下角绿色大按钮 `[ 发布版本 ]`；
2. 弹出版本发布清单弹窗，显示本次相比 `v7` 的变动统计：*“新增 2 块，修改 42 块，禁用 0 块”*；

4. 点击确认发布 ➔ 调用 `POST /api/v1/datasets/:id/releases`；
5. 顶栏第四张指标卡片 `索引版本` 从 `v7` 动态跳变为 `v8`；
