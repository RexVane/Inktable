# 16-AI应用-智能助手 (Assistants & Web Widget Integration)

> **所属模块**：Ordo 桌面知识工作台 · AI应用  
> **视觉设计稿**：[`planning/前端页面/16-AI应用-智能助手.png`](file:///d:/AIApp/Ordo/planning/前端页面/16-AI应用-智能助手.png)  
> **核心使命**：面向特定业务场景（产品问答、技术支持、销售资料）封装专属智能体，配置角色设定、欢迎语、推荐问题与模型参数，并支持一键生成安全签名 JS 脚本挂载至企业官方网站。  
> **架构定位**：**问答流程引擎的双重使命之二 —— 生产级多租户智能体与外部网站集成管线 (Production & External Integration)**。

## 一、双重使命与外部网站嵌入架构 (Dual-Role Architecture)

智能助手模块是 Ordo 连接“企业内网知识资产”与“外部真实业务场景”的枢纽：

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                 Ordo 统一问答流程引擎 (QA Pipeline Engine)                         │
└────────────────────────────────────────────────┬─────────────────────────────────────────────────┘
                                                 │
                 ┌───────────────────────────────┴───────────────────────────────┐
                 ▼                                                               ▼
  【内部知识工作台 · 智能助手管理 (Page 16)】                  【企业官网 · 悬浮交互组件 (Widget Runtime)】
  • 6 大选项卡全生命周期治理：                                 • 挂载形态：`<script src=".../widget.js">`
    1. 基本设置（名称、描述、语气、欢迎语、建议问题）          • 安全保障：Origin 来源白名单校验 + Client Secret
    2. 知识范围（指定绑定的知识库与发布版本，防止跨库越权）        防刷签名 + 动态 Token 交换
    3. 模型与提示词（推理模型、System Prompt、温度值）         • 生产请求：访客发送提问直接调用问答流程引擎，
    4. 网站接入（客户端端点、跨域白名单、嵌入脚本与密钥轮换）     端到端检索佐证并流式呈现，无感沉浸体验
    5. 发布版本（发布新版本、历史回滚、版本快照）              • 服务闭环：支持访客一键申请转人工客服工单，
    6. 用量与会话（近 7 天请求趋势、访客会话列表、转人工队列）     控制台坐席实时认领接管
```

## 三、本页面全部已实装 API 接口清单 (共 17 个)

| 序号 | 请求方式 | 接口路径 | 对应前端交互 / 按钮 | 核心业务定位与数据流 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/assistants` | 左侧助手列表与统计卡片 | 获取当前工作空间下全部助手列表、运行状态与今日统计指标 |
| **2** | `POST` | `/api/v1/assistants` | 页面右上角 `[+ 新建助手]` | 新建专属助手智能体（配置名称、图标、描述、绑定知识库） |
| **3** | `GET` | `/api/v1/assistants/:id` | 点击左侧助手卡片 | 获取该助手的完整配置（Prompt、温度、欢迎语、推荐问题、关联发布版本） |
| **4** | `PATCH` | `/api/v1/assistants/:id` | `[保存基本设置]` / 各 Tab 修改 | 更新助手名称、描述、回答语气、欢迎语与系统提示词 |
| **5** | `DELETE` | `/api/v1/assistants/:id` | 助手更多菜单 `[删除助手]` | 删除指定助手及其已绑定的接入端点 |
| **6** | `POST` | `/api/v1/assistants/:id/publish` | 顶栏右上角 `[发布新版本]` | 将当前草稿配置发布为线上不可变生产版本 |
| **7** | `POST` | `/api/v1/assistants/:id/pause` | 顶栏右侧 `[停用]` / `[启用]` | 临时暂停或恢复该助手对外部网站的问答服务 |
| **8** | `GET` | `/api/v1/assistants/:id/clients` | 切换到「网站接入」Tab | 获取已为该助手颁发的所有网站嵌入端点与凭据列表 |
| **9** | `POST` | `/api/v1/assistants/:id/clients` | 网站接入 `[+ 注册新接入端点]` | 注册跨域白名单并生成一次性 Client Secret 与 `<script>` 嵌入代码 |
| **10** | `POST` | `/api/v1/widget-clients/:id/rotate` | 客户端表格 `[轮换密钥]` | 轮换重置指定端点的签名密钥 Token，防止历史密钥泄漏 |
| **11** | `DELETE` | `/api/v1/widget-clients/:id` | 客户端表格 `[撤销]` | 注销作废指定网站客户端的接入授权 |
| **12** | `POST` | `/api/v1/public/widget/token` | (网站访客端公共接口) | 外部网站加载 `widget.js` 时使用 Client ID 与签名兑换短效 Session Token |
| **13** | `POST` | `/api/v1/public/widget/sessions` | (网站访客端公共接口) | 外部网站访客打开聊天浮窗时创建匿名会话 |
| **14** | `POST` | `/api/v1/public/widget/sessions/:id/messages` | (网站访客端公共接口) | 访客发送提问，后端执行同源 8 阶段流水线并流式返回佐证回答 |
| **15** | `POST` | `/api/v1/public/widget/sessions/:id/handoff` | (网站访客端公共接口) | 访客在网站中点击“联系人工客服”，创建转人工工单 |
| **16** | `GET` | `/api/v1/handoffs` | 「用量与会话」转人工队列 | 客服坐席查看外部访客转人工请求工单列表 |
| **17** | `PATCH` | `/api/v1/handoffs/:id` | 转人工队列 `[接管会话]` | 客服坐席认领、更新状态或完结工单 |
