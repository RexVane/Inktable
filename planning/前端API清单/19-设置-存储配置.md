# 19-设置-存储配置 (Storage, Cache & Database Backups)

> **所属模块**：Ordo 桌面知识工作台  
> **视觉设计稿**：[`planning/前端页面/19-设置-存储配置.png`](file:///d:/AIApp/Ordo/planning/前端页面/19-设置-存储配置.png)  
> **核心使命**：管理本地 SQLite 数据库文件物理路径、向量数据库存储目录、解析缓存清理与系统物理快照备份还原。

---

## 一、页面视觉核心组件与业务定位

* 【物理存储路径监控】：展示 SQLite 数据库文件（如 D:/AIApp/Ordo/data/ordo.db，38.4 MB）
* 【缓存管理】：一键清理临时解析切片与 OCR 临时图像，释放本地磁盘
* 【快照备份与还原列表】：备份包名称、创建时间、文件大小，提供 [创建备份] 与 [恢复] 按钮

---

## 二、本页面全部已实装 API 清单 (共 4 个)

| 序号 | 请求方式 | 接口路径 | 对应前端交互 / 按钮 | 核心功能说明 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/settings` | 页面对应操作 / 渲染 | 获取当前数据存储路径与已用磁盘空间大小 |
| **2** | `GET` | `/api/v1/backups` | 页面对应操作 / 渲染 | 获取历史全量物理快照备份列表 |
| **3** | `POST` | `/api/v1/backups` | 页面对应操作 / 渲染 | 一键生成当前知识库与数据库的物理打包备份 |
| **4** | `POST` | `/api/v1/backups/:id/restore` | 页面对应操作 / 渲染 | 从指定备份文件秒级物理还原系统 |

## 三、各接口详细契约（入参、出参及错误码）

### 1. 获取当前数据存储路径与已用磁盘空间大小 (`GET /api/v1/settings`)
* **请求方式**：`GET`
* **请求路径**：`/api/v1/settings`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 2. 获取历史全量物理快照备份列表 (`GET /api/v1/backups`)
* **请求方式**：`GET`
* **请求路径**：`/api/v1/backups`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 3. 一键生成当前知识库与数据库的物理打包备份 (`POST /api/v1/backups`)
* **请求方式**：`POST`
* **请求路径**：`/api/v1/backups`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 4. 从指定备份文件秒级物理还原系统 (`POST /api/v1/backups/:id/restore`)
* **请求方式**：`POST`
* **请求路径**：`/api/v1/backups/:id/restore`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`
