## 三、各接口详细契约（入参、出参及错误码）

### 1. 获取已配置的大模型与嵌入模型列表及健康状态 (`GET /api/v1/models`)
* **请求方式**：`GET`
* **请求路径**：`/api/v1/models`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 2. 新增模型服务提供商接入 (`POST /api/v1/models`)
* **请求方式**：`POST`
* **请求路径**：`/api/v1/models`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 3. 修改 Base URL、模型名称或更新 API Key (`PATCH /api/v1/models/:id`)
* **请求方式**：`PATCH`
* **请求路径**：`/api/v1/models/:id`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 4. 删除模型接入项 (`DELETE /api/v1/models/:id`)

* **请求路径**：`/api/v1/models/:id`

### 5. 模型连通性实时测试（发送 Ping 校验 Key 有效性与网络延迟） (`POST /api/v1/models/:id/test`)

* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`
