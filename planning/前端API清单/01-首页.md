### 2.2 本机会话初始化与自愈 (GET /api/v1/session/bootstrap)

- **接口定位**：首页与全站首屏启动、或任何请求捕获 401 会话失效时自动续签并重试。
- **请求方法**：`GET`
- **请求路径**：`/api/v1/session/bootstrap`
- **权限要求**：公开（拦截 cross-site 跨站请求）。
- **响应载荷 (200 OK)**：
  ```json
  {
    "data": {
      "csrfToken": "BRwz_9uX...",
      "expiresAt": "2026-09-04T04:54:25.289Z",
      "workspaceId": "ws_local"
    }
  }
  ```
- **响应头**：写入 `Set-Cookie: ordo_session=...; HttpOnly; SameSite=Strict; Max-Age=43200`

---

### 2.3 首页全局快捷搜索 (GET /api/v1/search)

- **接口定位**：在首页或任意页面按下 `Ctrl + K` 呼出全局搜索模态框。
- **请求方法**：`GET`
- **请求路径**：`/api/v1/search`
- **查询参数**：
  | 参数名 | 类型 | 必填 | 默认值 | 说明 |
  |---|:---:|:---:|:---:|---|
  | `q` | `string` | 是 | - | 搜索关键词 |
  | `limit` | `integer` | 否 | `30` | 返回条数上限 |
- **响应载荷 (200 OK)**：
  ```json
  {
    "data": [
      {
        "type": "knowledge_base",
        "id": "kb_prod",
        "title": "产品文档库",
        "subtitle": "包含企业核心技术规范",
        "route": "#/knowledge/config?kb=kb_prod"
      },
      {
        "type": "document",
        "id": "doc_manual",
        "title": "系统安装指南.pdf",
        "subtitle": "/产品文档库/安装部署",
        "route": "#/knowledge/parsing?document=doc_manual"
      }
    ]
  }
  ```

### 2.4 系统健康与版本环境 (GET /api/v1/health & /version)

- `GET /api/v1/health`: 快速返回 `{ status: "healthy", uptimeSeconds: ... }`，驱动状态圆点；
- `GET /api/v1/version`: 返回 `{ appVersion: "1.0.0", platform: "win32-x64", node: "v24.12.0" }`，驱动侧边栏底部版本标识。

## 三、前端异常与自愈机制

1. **401 会话失效自愈**：
   - 当调用 `GET /api/v1/dashboard` 遇到 401（会话超时或服务刚重启），`api.request()` 会在后台透明调用 `bootstrap()` 换取新 Cookie 并自动重发请求，用户不会看到红字报错；
2. **服务离线守护**：
   - 若服务离线不可达，展示优雅的单行重连提示横幅，不破坏首页三栏等高布局。
