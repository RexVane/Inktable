### 1.1 精简优化核心规则（用户亲自拍板）

1. **去除冗余及超前元素**：
   - 去掉右上角重复的大号“新建数据集”和“搜索数据集”按钮，收敛至左栏头部小巧的 `数据集 (3) [+]`；

2. **纯粹高效的 3 栏联动**：
   - **左栏（选集）**：展示数据集卡片，点击任意数据集，中间即刻切换到该数据集；
   - **中栏（看货）**：左边展示该数据集内的层级文件夹目录树，右边展示该目录下的文件表格，支持直接上传与新建文件夹；
   - **右栏（验货）**：**点击中间表格中的任意文件，右栏瞬间滑出该文件的具体属性信息（路径、大小、来源、时间）**！

## 二、页面所需全部接口契约

### 2.2 新建数据集 (POST /api/v1/datasets)

- **接口定位**：点击左栏头部 `[+]` 快速新建数据集。
- **请求方法**：`POST`
- **请求体 (Request Body)**：
  ```json
  {
    "name": "售后服务 FAQ",
    "description": "客户常见售后问题与标准答复汇总"
  }
  ```
- **响应 (201 Created)**：返回新创建的数据集对象，左栏自动插入并高亮选中。

---

### 2.4 获取当前目录下文件列表 (GET /api/v1/datasets/:id/files)

- **接口定位**：中栏右侧渲染当前选定文件夹下的文件表格。
- **请求方法**：`GET`
- **查询参数**：
  - `folderId`（可选，不传查根目录）
  - `page`（默认 1）
  - `limit`（默认 10）
- **响应载荷 (200 OK)**：
  ```json
  {
    "data": [
      {
        "id": "file_manual_01",
        "name": "Ordo 报表与分析手册.pdf",
        "fileType": "pdf",
        "processStatus": "completed",   // 👈 驱动【处理状态】列：completed(已完成) / parsing(解析中) / pending(待处理) / failed(失败)
        "chunkCount": 142,              // 👈 驱动【知识块】列：在 05 解析切块后回显真实切块数，刚导入时为 0
        "sizeFormatted": "2.34 MB",
        "folderPath": "03 功能说明 / 3.4 报表与分析",
        "source": "手动上传",
        "updatedAt": "2025-05-20 10:08"
      },
      {
        "id": "file_manual_02",
        "name": "系统配置与安装指南.docx",
        "fileType": "docx",
        "processStatus": "pending",     // 👈 待处理状态，知识块为 0
        "chunkCount": 0,
        "sizeFormatted": "1.82 MB",
        "folderPath": "02 安装部署",
        "source": "企业资料",
        "updatedAt": "2025-05-20 10:02"
      }
    ],
    "meta": { "total": 72, "page": 1, "limit": 10 }
  }
  ```

---

### 2.5 选中文件查看具体信息 (GET /api/v1/files/:id/inspect)

- **接口定位**：**核心交互**——用户在中间表格点击选中某份文件时，右栏即刻调用此接口呈现该文件的具体明细。
- **请求方法**：`GET`
- **请求路径**：`/api/v1/files/:id/inspect`
- **响应载荷 (200 OK)**：
  ```json
  {
    "data": {
      "id": "file_manual_01",
      "name": "Ordo 报表与分析手册.pdf",
      "fileType": "pdf",
      "folderPath": "03 功能说明 / 3.4 报表与分析",
      "source": "手动上传",
      "currentVersion": "v1.2.0 (2025-05-18 14:32)",
      "sizeFormatted": "2.34 MB",
      "sizeBytes": 2453667,
      "updatedAt": "2025-05-20 10:08"
    }
  }
  ```

---

### 2.6 新建文件夹 (POST /api/v1/datasets/:id/folders)

- **接口定位**：在当前目录下新建子文件夹。
- **请求方法**：`POST`
- **请求体**：`{ "name": "3.5 系统设置", "parentFolderId": "fld_03" }`

---

### 2.7 从数据集中删除文档 (DELETE /api/v1/datasets/:id/files/:fileId)

- **接口定位**：表格操作列点击【删除】按钮时触发，将文档移出该数据集。
- **请求方法**：`DELETE`
- **请求路径**：`/api/v1/datasets/:id/files/:fileId`
- **响应 (200 OK)**：`{ "success": true, "deletedDocId": "file_manual_01" }`

---

### 2.8 批量操作：多选批量删除 (POST /api/v1/datasets/:id/files/batch-delete)

- **接口定位**：在表格左侧勾选多个复选框后，点击底部操作浮条的【🗑 批量删除】。
- **请求方法**：`POST`
- **请求路径**：`/api/v1/datasets/:id/files/batch-delete`
- **请求体**：`{ "fileIds": ["file_01", "file_02"] }`
- **响应 (200 OK)**：`{ "success": true, "deletedCount": 2 }`

---

### 2.9 移动文件至指定文件夹 (PATCH /api/v1/datasets/:id/files/:fileId/move)

- **接口定位**：表格操作菜单或拖拽，将单份文档移动至指定新建的文件夹目录下。
- **请求方法**：`PATCH`
- **请求路径**：`/api/v1/datasets/:id/files/:fileId/move`
- **请求体**：`{ "targetFolderId": "fld_02" }`
- **响应 (200 OK)**：`{ "success": true, "fileId": "file_manual_01", "newFolderId": "fld_02", "newFolderPath": "02 安装部署" }`

---

### 2.10 批量移动文件 (POST /api/v1/datasets/:id/files/batch-move)

- **接口定位**：表格多选多个文档后，点击【移动到...】将选中的多个文件统一移动到指定文件夹中。
- **请求方法**：`POST`
- **请求路径**：`/api/v1/datasets/:id/files/batch-move`
- **请求体**：`{ "fileIds": ["file_01", "file_02"], "targetFolderId": "fld_02" }`
- **响应 (200 OK)**：`{ "success": true, "movedCount": 2 }`
