# 13-问答流程-构建提示词 前端 API 清单与交互契约

> **文档定位**：对应原型设计稿 [`13-问答流程-构建提示词.png`](file:///d:/AIApp/Ordo/planning/前端页面/13-问答流程-构建提示词.png)。  
> **流水线位置**：**问答流程诊断中枢·第七站：构建提示词（Stage 7: Prompt Synthesis & Token Budgeting）**。  
> **核心使命**：负责接收 Stage 6 重排保留的高相关 8 个证据切片，按预设的结构化模板组装「系统规则、助手角色、会话历史、用户问题、召回证据、引用规则、输出格式、安全约束」8 大模块，进行精确的 Token 预算管理（总预算 8,000 Tokens）与动态切片裁剪，执行敏感数据 PII 合规合规审计，最终生成向大模型（如 GPT-5）实际投递的完整 Prompt。

## 二、本页面全部 API 契约总览表 (共 7 个 API)

| 序号 | 请求方式 | 接口路径 | 对应前端组件 / 触发时机 | 核心功能说明 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/traces/:traceId/stages/prompt` | 页面初次加载 / 切换至此步骤 | **主数据源**：获取 8 大模板块定义、渲染后的正文、8 条召回证据切片、Token 预算分布（总 8000、证据 4210）、模型 GPT-5、模板 prompt-v12 |
| **2** | `GET` | `/api/v1/traces/:traceId/pipeline` | 顶部 8 阶段步进指示条 | 获取流水线各步骤执行状态与耗时 |
| **3** | `PUT` | `/api/v1/traces/:traceId/stages/prompt` | 底部 `[ 💾 保存模板 ]` 按钮 | **模板更新**：保存对系统规则、助手角色、引用规则或输出格式的修改，同步至生产模板版本或仅为本 Trace 生效 |
| **4** | `GET` | `/api/v1/traces/:traceId/stages/prompt/versions` | 底部 `[ 🔀 比较版本 ]` 按钮 | **版本 Diff 对比**：拉取 prompt-v12 与历史版本（如 prompt-v11）的差异比较字段，高亮新增/修改的 Prompt 指令 |
| **5** | `POST` | `/api/v1/traces/:traceId/stages/prompt/mask` | 底部 `[ 🛡️ 复制脱敏内容 ]` 按钮 | **安全脱敏拷贝**：自动对手机号、身份证、API Key、内部私网 IP 执行掩码脱敏后写入系统剪贴板 |
| **6** | `POST` | `/api/v1/traces/:traceId/replay` | 底部 `[ ⟳ 从此阶段重跑 ]` 按钮 | **重跑下游生成**：基于最新调整的 Prompt 内容，直接重新触发 Stage 8（回答生成），生成新的回复并评估答复质量 |
| **7** | `GET` | `/api/v1/traces/:traceId/stages/prompt/sensitive-scan` | 右侧「敏感数据扫描: 已通过 ∨」点击 | 获取敏感词库命中扫描详情（PII 检测 0 违规、内部越权词 0 命中、SQL注入关键词 0 违规） |

## 四、前端交互与动态状态机行为

1. **左侧快捷定位联动**：
   - 点击左侧导航项（如「召回证据」），中间卡片流平滑滚动至对应卡片并触发高亮边框。
2. **Token 预算超出告警**：
   - 若用户编辑中间卡片导致总 Tokens 超过 8,000，右侧预算条末尾变为红色告警颜色，剩余可用显示负数，底部「保存模板」与「进入回答生成」按钮自动禁用并弹出超限提示。
3. **实际发送预览开关切换**：
   - 右侧「实际发送预览」开关开启时，展示完全填充变量后的 Prompt 全文文本框，支持一键复制到剪贴板。
4. **阶段推进导向**：
   - 点击右下角绿色主按钮 `[ 进入回答生成 ➔ ]`，系统装载最终 Prompt  payload 并流转至 Stage 8 (`14-问答流程-回答生成`)。
