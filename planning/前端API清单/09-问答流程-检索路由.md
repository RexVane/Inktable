# 09-问答流程-检索路由 前端 API 清单与交互契约

> **文档定位**：对应原型设计稿 [`09-问答流程-检索路由.png`](file:///d:/AIApp/Ordo/planning/前端页面/09-问答流程-检索路由.png)。  
> **流水线位置**：**问答流程诊断中枢·第三站：检索路由（Stage 3: Retrieval Routing & Channel Dispatch）**。  
> **核心使命**：负责接收规范化提问及问题特征向量，结合意图识别（如配置操作类、事实概念类、实体关系类、结构化查询类）与当前知识库底层的索引健康状态，智能决策调度分发至四大检索通道（向量检索 Dense Vector、全文检索 Sparse BM25、知识图谱 Graph RAG、结构化查询 Structured Metadata/SQL），动态分配各通道的 Top-K 预算配额、超时熔断阈值与加权比例，并提供自动降级兜底策略。

## 二、本页面全部 API 契约总览表 (共 8 个 API)

| 序号 | 请求方式 | 接口路径 | 对应前端组件 / 触发时机 | 核心功能说明 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/traces/:traceId/stages/route` | 页面初次加载 / 切换到本步骤 | **主数据源**：获取当前 Trace 路由策略（输入问题、4项路由基础配置、4通道DAG分支状态、通道参数与预估表、4项路由依据、综合置信度） |
| **2** | `GET` | `/api/v1/traces/:traceId/pipeline` | 顶部 8 阶段步进指示条 | 获取 8 阶段执行状态与耗时大盘 |
| **3** | `PUT` | `/api/v1/traces/:traceId/stages/route` | 底部 `[ ✏️ 编辑路由 ]` 弹窗/抽屉提交保存 | **动态调参**：修改各通道开关（启用/禁用）、TopK 配额、超时熔断时间（ms）、融合加权比重、兜底降级通道 |
| **4** | `POST` | `/api/v1/traces/:traceId/stages/route/simulate` | 底部 `[ 🧪 模拟运行 ]` 绿色按钮 | **沙箱推演**：不破坏历史 Trace，传入修改后的通道权重与阈值，即时计算预估召回、预估耗时、预估成本与综合置信度 |
| **5** | `POST` | `/api/v1/traces/:traceId/replay` | 底部 `[ ▶ 从此阶段重跑 ]` 按钮 | **流水线级联重放**：以当前设定的检索路由通道策略为起点，重新执行 Stage 4~Stage 8（召回、融合、重排、Prompt、生成），派生新 Trace |
| **6** | `GET` | `/api/v1/traces/:traceId/stages/route/indexes` | 右侧「可用索引」健康度弹窗/悬停 | 查询向量库（v2.1）、BM25 全文分词库（v1.9）、图数据库（v1.4）各索引引擎的具体健康指标、分片状态与版本详情 |
| **7** | `GET` | `/api/v1/traces/:traceId/stages/route/intent` | 右侧「意图匹配」分析卡片点击 | 获取意图识别分类器详细概率分布（配置指导/操作类 0.86、概念解释类 0.08、故障排查类 0.04、其他 0.02）及提取特征词 |
| **8** | `GET` | `/api/v1/traces/:traceId/stages/route/logs` | 开发者排障 / 路由决策日志查看 | 获取规则判定树路由链路日志（命中意图规则、知识库索引健康检查、ACL 权限过滤及通道分发记录） |

## 四、前端交互与动态状态机行为

1. **通道卡片与表格双向联动**：
   - 当点击拓扑图中某通道卡片（如点击「向量检索」）时，下方表格自动高亮对应行并滚动聚焦；
   - 拓扑图上的标签与圆点颜色（绿色代表「已启用」，灰色代表「未启用」）与表格状态列保持绝对同步。
2. **编辑路由弹窗校验**：
   - 各通道权重（Weight）总和在保存时若不等于 1.00，系统弹出平滑归一化（Normalize Weights）确认提示；
   - 超时时间限制不得小于 100ms 或大于 5000ms；
   - TopK 配额范围限制为 `1 <= TopK <= 100`。
3. **模拟运行沙箱机制**：
   - 点击 `[ 🧪 模拟运行 ]` 时，按钮呈现 Loading 动效，推演结果在当前页面以浮层/对比模式展示，不改变原有链路历史。
4. **从此阶段重跑 (Replay)**：
   - 点击重跑后，界面弹出 Toast 提示「已创建衍生重跑链路 QA-2025-0520-0086-R1」，并自动跳转至新 Trace 流水线或流转到 Stage 4（多路召回）。
