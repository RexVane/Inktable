* 【分类聚合匹配列表】：按【文档】、【知识块】、【智能助手】、【系统功能】分组高亮呈现
* 【键盘快捷导航提示】：↑ ↓ 切换选项目，Enter 直达目标页面，Esc 退出

## 三、各接口详细契约（入参、出参及错误码）

### 1. 输入关键字发起全局极速搜索，跨知识库、文档、分块与系统菜单秒级聚合匹配 (`GET /api/v1/search?q=:keyword`)
* **请求方式**：`GET`
* **请求路径**：`/api/v1/search?q=:keyword`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 2. 开发者调试自省 OpenAPI 3.0 元数据 (`GET /api/v1/openapi.json`)
* **请求方式**：`GET`
* **请求路径**：`/api/v1/openapi.json`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`
