# 21-状态-新对话选择知识库 (Modal: Select Knowledge Base for New Chat)

> **所属模块**：Ordo 桌面知识工作台  
> **视觉设计稿**：[`planning/前端页面/21-状态-新对话选择知识库.png`](file:///d:/AIApp/Ordo/planning/前端页面/21-状态-新对话选择知识库.png)  
> **核心使命**：点击发起新对话或切换提问背景时弹出的模态框，用于快速选取目标知识库并加载其发布版本。

---

## 一、页面视觉核心组件与业务定位

* 【知识库单选卡片列表】：展示企业知识库、产品手册、架构规范等卡片，带勾选光圈
* 【版本与权限提示】：展示当前知识库生效的只读发布版本（如 Release v7）
* 【底栏控制按钮】：[ 取消 ]、[ 确认并开始问答 ] 绿色主按钮

---

## 二、本页面全部已实装 API 清单 (共 2 个)

| 序号 | 请求方式 | 接口路径 | 对应前端交互 / 按钮 | 核心功能说明 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/knowledge-bases` | 页面对应操作 / 渲染 | 获取全部可检索的活跃知识库列表（名称、文档数、切块数） |
| **2** | `POST` | `/api/v1/conversations` | 页面对应操作 / 渲染 | 创建会话并绑定所选定的知识库 ID，完成后关闭弹窗进入对话流 |

---

## 三、各接口详细契约（入参、出参及错误码）

### 1. 获取全部可检索的活跃知识库列表（名称、文档数、切块数） (`GET /api/v1/knowledge-bases`)
* **请求方式**：`GET`
* **请求路径**：`/api/v1/knowledge-bases`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`

### 2. 创建会话并绑定所选定的知识库 ID，完成后关闭弹窗进入对话流 (`POST /api/v1/conversations`)
* **请求方式**：`POST`
* **请求路径**：`/api/v1/conversations`
* **鉴权说明**：携带有效 Cookie / Session 会话凭证
* **响应标准**：HTTP 200 OK，标准包装格式 `{ "code": 0, "data": ... }`
