# 17-设置-通用 (General Settings)

> **所属模块**：Ordo 桌面知识工作台  
> **视觉设计稿**：[`planning/前端页面/17-设置-通用.png`](file:///d:/AIApp/Ordo/planning/前端页面/17-设置-通用.png)  
> **核心使命**：管理工作台基础偏好，包含系统主题（浅色/深色/跟随系统）、多语言环境与实验性特性开关。

---

## 一、页面视觉核心组件与业务定位

* 【主题切换选项】：单选切换 浅色 (Silver) / 深色 (Nebula) / 跟随系统，实时切换全局 CSS 变量
* 【语言环境设置】：界面多语言选择（简体中文 / English）
* 【工作台偏好】：折叠侧边栏默认状态、自动保存间隔
