# 06-知识库-知识库管理 前端 API 清单与交互契约

> **文档定位**：对应原型设计稿 [`06-知识库-知识库管理.png`](file:///d:/AIApp/Ordo/planning/前端页面/02-知识库-数据配置.png)（原数据配置）。  
> **流水线位置**：**知识资产中枢·第一站：知识库管理（Knowledge Base Management Workbench）**。  
> **页面形态说明**：本页面为一体化知识库管理工作台（**非向导分步式，无需 3 步跳转**），采用双栏自适应布局：左栏管理已有知识库列表与基础信息登记，右栏统一配置向量数据库引擎、安全凭据、隔离 Namespace 与底层切片索引策略。

## 二、本页面全部已实装 API 清单 (共 9 个 API)

| 序号 | 请求方式 | 接口路径 | 对应前端交互 / 按钮 | 核心功能说明 |
|:---:|:---:|---|---|---|
| **1** | `GET` | `/api/v1/knowledge-bases` | 页面初次加载 / 左栏列表 | 获取当前工作空间全部已有知识库列表（名称、描述、状态、关联数据集数） |
| **2** | `POST` | `/api/v1/knowledge-bases` | 右下角 `[ 保存知识库 ]` / 新建 | 创建新的知识库实体（校验名称非空、分配独立 ID 与存储空间） |
| **3** | `GET` | `/api/v1/knowledge-bases/:id` | 左栏点击任意已有知识库 | 获取选中知识库的详细配置信息，并在右栏自动填充回显 |
| **4** | `PATCH` | `/api/v1/knowledge-bases/:id` | 修改名称/说明后点击保存 | 更新知识库基础元数据（名称、描述、所属空间） |
| **5** | `DELETE` | `/api/v1/knowledge-bases/:id` | 左栏知识库卡片 `[ 删除 ]` 按钮 | 物理或软删除指定知识库及其级联索引映射 |
| **6** | `GET` | `/api/v1/knowledge-bases/:id/impact` | 点击删除前呼出影响评估 | **安全守门员**：评估删除该库将对下游多少个智能助手、问答对话产生破坏影响 |
| **7** | `POST` | `/api/v1/connectors/:id/test` | 右栏 `[ 测试连接 ]` 按钮 | 对配置的外部向量数据库实例发送 Ping 心跳包，校验 Host、Port 与密钥有效性 |
| **8** | `GET` | `/api/v1/knowledge-bases/:id/index-profiles` | 右栏下方切片策略加载 | 获取该知识库绑定的向量索引策略（Chunk Size、Overlap、度量算法、维度） |
| **9** | `POST` | `/api/v1/index-profiles/:id/default` | 点击设为默认索引模板 | 将当前调整好的分块切片策略设为系统全局默认模板 |

## 三、各接口详细契约 Schema

### 1. 获取知识库列表 (GET /api/v1/knowledge-bases)
* **响应载荷 (200 OK)**：
```json
{
  "code": 0,
  "data": [
    {
      "id": "kb_prod_docs",
      "name": "核心产品文档库",
      "description": "用于统一沉淀核心产品的使用指南、架构文档及运维手册",
      "workspaceId": "ws_default",
      "status": "ready",
      "vectorEngine": "sqlite_vss",
      "documentCount": 128,
      "chunkCount": 8652,
      "updatedAt": "2026-09-03T18:20:00Z"
    }
  ]
}
```

---

### 2. 创建或更新知识库 (POST /api/v1/knowledge-bases)
* **请求体 (Payload)**：
```json
{
  "name": "核心产品文档库",
  "description": "企业核心产品技术规范与API手册",
  "vectorEngine": "sqlite_vss",
  "host": "sqlite://data/ordo.db",
  "collection": "kb_prod_docs",
  "chunkSize": 512,
  "chunkOverlap": 50,
  "metric": "cosine"
}
```
* **响应载荷 (200 OK)**：返回创建成功的知识库详情对象，状态码 200，并弹出 Toast 提示：`"✓ 知识库「核心产品文档库」已创建成功"`。

---

### 3. 删除前影响评估 (GET /api/v1/knowledge-bases/:id/impact)
* **响应载荷 (200 OK)**：
```json
{
  "code": 0,
  "data": {
    "knowledgeBaseId": "kb_prod_docs",
    "impactedAssistants": [
      { "id": "ast_support", "name": "官方网站智能客服" }
    ],
    "activeConversationsCount": 42,
    "hasUnpublishedRevisions": false,
    "warningMessage": "删除该知识库将导致 1 个在线智能助手失去检索能力，请谨慎操作！"
  }
}
```

## 四、界面像素级元素与按钮绑定映射

| 区域 | 界面元素 / 按钮 | UI 表现形式 | 对应 API / 数据绑定 |
|---|---|---|---|
| **页面头部** | **页面标题** | `知识库管理` | 静态大标题 |
| **页面头部** | **`[ + 新建知识库 ]`** | 白色线框按钮 | 清空表单进入新建态 |
| **页面头部** | **`[ 保存全局配置 ]`** | 绿色主按钮 | 批量持久化左栏与右栏设置 |
| **左栏** | **已有知识库列表** | 竖向卡片流，当前库高亮浅绿背景 | 遍历绑定 `GET /api/v1/knowledge-bases` |
| **左栏** | **`[ 删除 ]` 按钮** | 红色文字小按钮 | 先调用接口 6 评估影响，再调用接口 5 删除 |
| **左栏** | **知识库名称输入框** | 单行文本框（必填标红星） | 双向绑定 `kb.name` |
| **左栏** | **知识库说明文本框** | 多行 textarea | 双向绑定 `kb.description` |
| **右栏** | **引擎类型选择框** | 自定义下拉选择器 | 支持选择 SQLite / Milvus / Qdrant 等 |
| **右栏** | **服务地址 / 路径** | 单行文本输入框 | 绑定 `kb.host` |
| **右栏** | **安全凭据与密钥** | 带小眼睛 👁 可见性切换框 | 绑定安全密码凭据 |
| **右栏** | **Collection / Namespace** | 单行输入框 | 向量隔离命名空间 |
| **右栏** | **分块大小与重叠长度** | 数字输入框 (512 / 50) | 绑定 `indexProfile.chunkSize` / `chunkOverlap` |
| **右栏** | **度量算法单选** | Cosine / IP / L2 单选圆圈 | 绑定 `indexProfile.metric` |
| **右栏底部**| **`[ 测试连接 ]` 按钮** | 白色线框按钮 | 点击调用接口 7，成功变绿标 `✓ 就绪` |
| **右栏底部**| **`[ 保存知识库 ]` 按钮**| 绿色主按钮 | 点击调用接口 2 或 4 提交保存并刷新左栏 |
